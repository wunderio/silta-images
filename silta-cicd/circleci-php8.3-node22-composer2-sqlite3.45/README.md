# silta-circleci
A docker image used circleCI, based on `cimg/php:8.3.x` with the following additions:

- Composer configured correctly
- Vim, useful for debugging
- kubernetes and helm
- Node.js
- Yarn

## Versions
- PHP: 8.3.35
- Composer: 2.8.4
- Node: 22.23.3
- Yarn: 1.22.22
- Helm: v3.22.0
- SQLite: 3.45
